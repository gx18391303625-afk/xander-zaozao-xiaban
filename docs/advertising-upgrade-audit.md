# 广告策略升级前的兼容性修复

本次修改校验与执行基础，不代表新策略功能已经发布。保留现有插件身份、写入开关、逐份提案审批与回读流程。

## 修复范围

- 独立运营模式不再跳过已提供上下文的 ID、哈希和利润约束；没有真实选品链路时仍不要求编造。
- 广告继承词库中的用途资格和阶段依据，不能自行把上游不允许的词改成可投放。阶段依据必须来自实际当前观察。
- 费用问题交利润模块，在售补货问题交补货模块；产品层面判断交用户。已冻结的选品路由仅保留历史审计兼容。
- SP 新设竞价策略使用执行器支持的枚举；已有 RULE_BASED 可以保留或退出，不能被当成新增能力。自由文字不能冒充策略参数。
- 快速广告经济线拒绝负成本、越界百分比、错误类型和未知字段。缺失输入继续标记缺失，不补成已确认的零。利润底线耗尽广告空间时返回 BLOCKED，避免“就绪”状态与无广告空间的结论矛盾。
- 关键词创建核对完整分页，未知结果按稳定目标身份防重；回读检查 ID、父级、正负类型、状态、词、匹配方式及竞价。
- 未知预算周期不能当作日预算；金额舍入后必须仍为有效正数。

## 替换的旧指令

“任何操作只能改一个字段”改为遵循实际操作合同：普通标量修改保持单字段，已支持的组合操作展示全部影响范围。未指定字段仍需保留。

能力判断以实际工具清单为准，删除把已经支持的创建、位置加价、预算规则和投资组合一概列为未实现的旧例子。

## 保留的有效规则

- 新品在转化数据尚不稳定时，仍可在明确批准的预算、损失、时限和退出条件内学习。
- 利润底线、总预算、库存和证据约束继续生效。
- 结构校验通过只代表可以进入下一步审核，不代表账户执行已获授权或已成功。
- 不完整或含糊的创建回执不能自动重试，必须先核实结果。

## 后续能力边界

| 建议能力 | 当前边界 |
| --- | --- |
| 出价与流量校准、并行测试容量 | 可分析；本次没有新增试验调度器 |
| 基础竞价与广告位联合调整 | 已有独立执行操作；组合不具备事务原子性，须分别核对结果 |
| 多期市场需求、供给与集中度诊断 | 需要时间一致的数据和显式诊断字段；本次没有新增完整分析器 |
| 分时实验 | 现有时间规则用于预算，不能称作分时 bid 排程 |
| 关键词证据追踪 | 本次加强交接一致性；没有新增可视化界面 |

完整 Python 策略包仍使用闭合字段集合。不得删除字段校验，或把广告位、分时参数塞进自由文字来伪造支持。独立经济计算器能处理的组合计费模型，也不能直接视为完整策略包已经支持。

## 验证边界

修复前基线 436 项通过。新增 35 项回归后，最终 471 项通过：Node 161、广告策略 221、Listing 45、词库 17、竞品 27。异常回执、字段类型及策略别名还在对应测试内按多种输入逐一验证。

回归覆盖本地校验、合成 HTTP 回执和隔离配置。没有改动真实 Amazon 商品、广告、开关或凭证；本次验证不构成真实账户上线验证。
