# DSH 原生开关页 · 验收记录

## 首轮本地验收范围

- 首轮开发基于 Xander 2.9.2，以下记录发生在 v2.10.0 发版之前；不作为远端已发布的证明。
- DSH Desktop：0.2.2-rc.3，使用现有运行实例与设置页，不另起替代 DSH 服务。
- 在「设置 → Xander」仅提供能力开关、搜索、刷新与完整网页入口；其余功能保留原入口。

## 已核验

- `node --test test/*.test.js`：**586 项通过，0 失败**。
- 新增开关桥测试共 9 项：默认读不写、鉴权与浏览器身份、CSRF、严格参数与体积限制、未知/规划能力、实际临时开关文件与审计复用、旧版本冲突、失败不重试、延迟正文中卸载/撤销权限、按需面板生命周期与路由清理、Client 分发契约。
- 所有写入测试使用独立临时 `XANDER_HOME`，清理前校验绝对路径；未拨动真实用户开关，未执行亚马逊写入。
- Client/Host JavaScript 语法与 `git diff --check` 通过，版本一致性检查通过。
- `npm pack --dry-run --json` 确认包含 Client、Host 设置桥、补丁、中文/英文元数据与原有图标等资源。
- 通过当前 DSH 插件管理器安装本地仓库，结果 `application: applied`、无应用警告；当前 profile 从旧安装 2.5.1 切到本地 2.9.2 源码。
- 真实 Desktop 设置导航已显示 Xander；原生页面成功读取当前开关汇总与各行状态。
- 真实 Desktop 中检查了深色和浅色主题；搜索「紫鸟」可筛选对应行；未点击真实开关。
- 独立安全审查与独立 UI/UX 审查完成；长列表反馈被滚走的问题已采用容器内 sticky 反馈条修正，保留 ARIA 状态通知。

## 未作为通过项宣称

- 没有对真实数据执行开关写入，所以真实保存/冲突/错误反馈和动画手感不属于本次人工实测；这些分支有隔离测试或代码审查依据。
- 未对全部窄屏、屏幕阅读器或其他 DSH 版本/远程部署作兼容承诺。
- 原完整网页启动、重复使用和卸载清理有隔离测试；未为验收向模型输出原网页的一次性口令。
- 浏览器认证、browserPeer 与 CSRF 门禁不防御同源恶意脚本、浏览器自动化或同机任意代码；不注册开关写工具也不意味着能阻止任意本机程序。AI 不得代用户拨动开关的规则保持不变。

## v2.10.0 发布前复核

- 四处版本清单、README 与 DSH 固定版本安装链接同步到 2.10.0；DSH 引擎要求提高到 `^0.2.2-rc.3`，其他宿主入口不加载 DSH Client。
- 独立发版审查发现并修复 Desktop 外开 URL 路径及原面板异步监听错误；新增 4 种真实启动函数错误注入、实际端口冲突回退及 Host 失败回收测试。
- 最终 `npm run check:version`、592 项 Node 回归、全部技能 Python 回归通过；测试仍使用隔离数据，不改变真实权限。
- 发布通过仓库既有 tag → CI → npm OIDC → GitHub Release 工作流；远端成功状态应以工作流、npm 元数据与 Release 附件分别核验，以上本地记录不替代远端状态。
