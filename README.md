<h1 align="center">Xander（自用）早早下班小助手</h1>

<p align="center">给亚马逊个人卖家用的本地运营插件 · 支持 Claude 和 Codex（GPT）<br>让日常运营更轻松，把时间还给生活。</p>

## 这是什么

装进 Claude Code 或 Codex 之后，你可以直接用中文交代亚马逊的日常活：

> “分析我最近 7 天的销售、广告、库存和利润，最需要关注什么？”
> “这几个竞品和我比，差在哪？”
> “帮我把这个 SKU 的五点重写一下。”
> “按现在的销量和交期，每个颜色要补多少箱？”
> “这几个关键词的竞价降 15%，那个没出单的词加否定。”

它包含 **1 个总协调 + 6 个运营模块**（不含选品）：

| 模块 | 能做的事 |
|---|---|
| 竞品分析 | 锁定对标、拆解页面与买家反馈、对比同词表现，给出有证据的突破口 |
| 关键词词库 | 采集、去重、分类、前台验证，交接给 Listing |
| Listing | 按产品事实写/改/审标题、五点、描述、后台词，带合规审计 |
| 广告 | 盈亏线核算、新品/老品分开诊断、调竞价/预算/开停/否词 |
| 补货 | 续航、断货日、情景补货量、整箱与 MOQ |
| 利润 | 日常预估、期间复盘、结算对账，缺项不硬凑 |

## 和别的工具不一样的地方

- **数据不出你的电脑。** 没有服务商、没有中转服务器。店铺和广告令牌存在系统钥匙串里（macOS 钥匙串 / Windows DPAPI），AI 也拿不到原文。
- **写入像开灯。** 每一类改动（改竞价、改预算、改标题、改价……）都有一个开关，**默认全部关闭**。你在本地开关面板里自己点开，支持一键全开/全关；紫鸟浏览器控制是单独的开关。AI 只能看开关，不能拨开关。
- **每次改动都要你批准。** AI 先生成精确提案（改哪个对象、原值多少、新值多少、为什么），你说“批准”才执行，只执行一次，执行后自动回读核对。断网超时不会重复提交。
- **有安全上限。** 竞价、预算、售价单次改动超过你设的幅度（默认 ±50% / ±100% / ±20%），直接拒绝。
- **会记事。** 店铺档案库记住后台没有的东西：采购价、头程、箱规、交期、认证、过往决策。改价保留历史，利润按当期成本算。
- **不硬凑数字。** 缺的就是缺，不当 0；第三方估算和模拟结果都会标出来。

## 快速开始（约 20 分钟）

**1. 装 Node.js**：到 https://nodejs.org 下载 **LTS** 版（22.13 或更高），一路下一步。

**2. 装插件**

- Claude Code：
  ```
  /plugin marketplace add gx18391303625-afk/xander-zaozao-xiaban
  /plugin install xander-zaozao-xiaban@xander-zaozao
  ```
- Codex：
  ```
  codex plugin marketplace add gx18391303625-afk/xander-zaozao-xiaban
  ```
  然后在 ChatGPT 桌面版的“插件”目录里安装。找不到的话见 [手动安装](docs/新手接入教程.md#8-手动安装备用)。

**3. 接入店铺**：下载本仓库（或在插件目录里）打开终端运行：
```
npm link            # 让 xander 命令可用（只需一次）
xander setup        # 接入向导：店铺、广告、卖家精灵、云备份、紫鸟
xander doctor       # 体检：逐项测试是否接通
```
不会的地方直接问 AI：“带我接入店铺”。详细图文见 **[新手接入教程](docs/新手接入教程.md)**。

**4. 打开开关面板**：
```
xander panel
```
建议第一次先打开“演练模式”，再开一个低风险开关（比如“新增否定关键词”）把完整流程走一遍。

## 写入开关一览

| 分组 | 开关 |
|---|---|
| SP 商品推广 | 活动开/停、活动日预算、广告组开/停、广告组默认竞价、投放竞价（关键词/商品/自动）、投放开/停、广告商品开/停、新增关键词、新增否定关键词（广告组级/活动级） |
| SB 品牌推广 | 活动开/停、活动日预算、投放竞价、投放开/停 |
| SD 展示型（Beta） | 活动开/停、活动预算、投放竞价、投放开/停 |
| Listing | 标题/五点/描述/后台词、售价、自发货库存 |
| 紫鸟浏览器 | 代为点击/填写（单独开关，不跟随一键全开） |
| 规划中 | 新建广告活动、广告位加价、预算规则、图片、A+、优惠券、FBA 货件 |

归档、删除这类不可恢复的操作故意不提供。

## 用的都是亚马逊最新接口（2026-10 核对）

| 用途 | 接口 | 说明 |
|---|---|---|
| 广告管理 SP/SB | Amazon Ads API **v1 统一接口**（`/adsApi/v1/...`） | 官方正式版，替代 SP v3 / SB v4 |
| 广告管理 SD | SD 原接口（`/sd/...`） | 官方尚未发布 SD 统一接口迁移资料，发布后跟进 |
| 广告报表 | **Reporting API v1**（`/adsApi/v1/create\|retrieve/reports`） | 官方仍为测试版；搜索词、投放、推广商品三类报表的 v1 字段未公开，暂自动用 v3（2027-06-30 关停），并在结果里注明 |
| 订单 | Orders **v2026-01-01** | v0 已弃用（2027-03-27 下线），插件拒绝调用 |
| 财务 | Finances **v2024-06-19** | v0 已弃用（2027-08-27 下线），插件拒绝调用 |
| FBA 入库 | Fulfillment Inbound **v2024-03-20** | v0 已下线 |
| Listing / 目录 / 报表 / 库存 | Listings 2021-08-01、Catalog 2022-04-01、Reports 2021-06-30、FBA Inventory v1 | 均为当前最新版 |

已弃用的旧接口和报表类型（如旧版结算报表 `GET_V2_SETTLEMENT_REPORT_DATA_FLAT_FILE`）插件会直接拒绝，并告诉 AI 应该改用哪个新接口。

## 常用命令


## 数据放在哪

默认在 `~/.xander-zaozao/`（可用环境变量 `XANDER_HOME` 改）：

```
config.json       店铺别名、区域、站点、广告 profile、设置（不含密钥）
switches.json     开关状态和安全上限
archive.db        店铺档案库（SQLite）
proposals/        每一份改动提案
ledger.jsonl      写入日志
reports/          下载的报表
```

## 安全说明（请读一下）

- 开关挡的是“误操作”和“没想清楚就执行”，不能挡一个被恶意指令劫持的 AI 去改你电脑上的文件。所以：别让 AI 读来路不明的文件或网页后直接执行改动；改动前认真看提案；不用的开关及时关掉。
- 如果你在聊天里贴过密钥，请到对应后台重新生成。
- 紫鸟控制是模拟人工点击，页面改版就可能失败，属于高风险能力，默认关闭。
- 本工具不构成财务、法律或合规建议；所有改动的最终决定权在你。

## 已知限制与待验证

- 这一版用按官方规范编写的模拟接口完成了全流程测试，**还没有在大量真实账户上验证**。SD 写入标为 Beta，第一次用建议先开演练模式。
- Reporting API v1 官方仍是测试版，返回格式可能变化；遇到“已完成但没有下载地址”这类提示，请提 Issue。
- 搜索词 / 投放 / 推广商品报表暂用 v3，2027-06-30 前需要换成 v1（等官方公开字段名）。
- 紫鸟 WebDriver 的接口参数以紫鸟官方文档为准，不同版本可能不同。
- 卖家精灵 MCP 由你自己在宿主里连接，本插件不经手。

## 开发

零依赖，只用 Node 自带功能（内置 SQLite、fetch、WebSocket）。

```
npm test          # 40 项测试：v1 统一接口写入全流程、v1/v3 报表、旧接口拦截、故障保护、计算器、档案库、面板安全、MCP 协议、S3 签名
```

技能里的 Python 脚本（竞品评分、广告经济、Listing 校验等）各自带回归测试：`python3 skills/<技能>/scripts/run_regression_tests.py`。
