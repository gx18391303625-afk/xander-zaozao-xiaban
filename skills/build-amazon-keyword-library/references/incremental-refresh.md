# 精准增量刷新

已有词库时使用；新建库仍执行完整建库流程。减少的是重复获取，不是证据标准或用户明确指定范围。

## 选择本轮对象

先记录基线主库版本、产品/站点、源时间窗、本轮范围及触发原因。项目有共享数据版本机制时，按项目说明校验并保留 `inputBindings(id/version/sha256)`；已撤销、替代、越界或过期依据不能因有旧 ID 而继续当当前证据。

优先队列：

- `NEW`：新来源出现、尚未判断匹配/意图的词。
- `MATERIAL_CHANGE`：同源同口径指标变化可能改变需求、阶段资格或角色；记录比较窗口和阈值依据。
- `DISPUTED`：产品匹配、意图、品牌/主张、SERP 或来源冲突可能改变结论。
- `INVALIDATED`：依赖的产品事实、主张、竞品身份或证据有效性变化；只追踪受影响词/词族，不扩展无关产品。
- `REUSED`：无上述触发且证据仍适用，保留原观察时间、来源、复用理由；不能把本轮运行时间写成新的采样时间。

没有全量新数据不能宣称全库“无变化”。记录实际检测来源、检测时间窗及未检测部分；用户指定新月份或全部 ASIN 全量刷新时，执行该范围的采集，不以增量之名省略。基线未覆盖或原来采集失败的指定 ASIN 仍列缺口；只有有效覆盖才可复用。

## 采集与判定

复用同账户/站点/日期/配置且满足本轮新鲜度的已完成报告或进行中的任务，不重复申请；需要更新归因或新周期时按项目取数规则刷新。源不支持逐词筛选时，可取覆盖目标的最小报告/分页集合，完整保存本次返回 RAW，再仅重算受影响词；不要声称做到了接口不支持的局部取数。

同范围可用的一方热门搜索词/SQP/广告搜索词优先，SellerSprite 补覆盖。搜索频率排名、点击占比、转化份额、第三方搜索量、账户广告 CVR 各保留定义、分母与时间，不相加、不互相覆盖，也不把不同周期差异自动当趋势。实质变化依据项目阈值或当前分布与决策影响，不固化通用百分比。

角色仍按产品/主张门禁、需求、SERP、竞争背景判断。新高流量词也不能绕过产品匹配；事实被撤销时先收回依赖资格，再补证。

需要新做前台复核的词遵守 [serp-validation.md](serp-validation.md)：可见 10 页以上检查前 10 页，不足 10 页检查全部可见页。增量只调整本轮选词范围，不缩短这一深度。可复用的旧 SERP 必须仍与当前形态/意图/对标条件相容，记录原深度和日期；有争议或失效就重查，无法查明则标缺口。

## 变化交付

完整主库与全部原始行继续保留。给变化行附 `keyword_id / before_role / after_role / delta_type / reason / evidence_ids / source_window / next_step`：

- `ADDED`：新增主库行，仍可处于待核验/隔离角色，不等于核心词。
- `DOWNGRADED`：已有资格或优先角色下调。
- `EXCLUDED`：移出正向使用范围，原词和原因仍在底稿；不是删除 RAW，也不是广告否词授权。
- `REVIEW`：证据不足/冲突、需补证，不能当已确认变化。
- `UPGRADED`：新证据确实释放角色时记录；其余不变行为 `REUSED` 或仅快照更新。

正文先给新增、降级、剔除、待复核（有升级再补列），再给有效复用/本轮检测覆盖和完整底稿链接。现有词库角色与运行状态不被这些变化标签替代。局部刷新可完成其约定范围，但不能借此把仍有核心词源缺口的全库改标 `COMPLETE`。
