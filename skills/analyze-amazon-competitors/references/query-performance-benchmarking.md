# 我方与竞品的关键词表现及销量对标

用于同词点击率、转化率、关键词购买量及商品总销量的单期或连续期间对比。适用于不同类目、产品和 Amazon 站点；以下输入由当前任务绑定，不保存某次研究的产品名单或数值。此模式只做分析；广告执行仍由广告策略技能按当前授权处理。

## 1. 绑定本次范围

- 从当前会话和项目资料取得站点、币种、报表时区、我方 ASIN/父子关系、竞品 ASIN、精确关键词、起止日期与输出偏好。仅对影响结果且无法确认的输入补问；不沿用另一产品的默认值。
- 保留用户全部竞品及顺序。品牌相同也按 ASIN 区分；用户只要指定词，就不扩成全站或完整词库。只为大小写/多余空格规范化关联，词序、单复数和近义词仍分别处理。
- 点击率与转化率使用相同粒度，通常为同站点、同词、同期的单个子 ASIN。若用户要求父体关键词表现，先取得我方与竞品一致的父体覆盖；无法取得时保留子体比较并说明缺口，不能把我方父体与竞品单款作为同口径结果。
- 父体总销量另作一组比较，核对各方覆盖。单款搜索表现和父体总销量可以并列辅助判断，不能直接相除或当成同一层级的表现。
- 用户指定期间优先。需要趋势但未指定窗口时，可用最近三个已发布的完整周；记录实际日期和报告周号，不能把 ISO 周号、抓取日或未结束的本周替代报表覆盖日期。

## 2. 按可用字段取数

先查看当前环境的可用工具与权限，复用仍适用的原始报表。可用连接器/API、后台导出或页面明细；不假定固定工具名、网址会话、文件路径或某类目一定有完整字段。遵守已有数据源、调用量与付费限制。

- **我方关键词表现**：优先 SQP 的 ASIN 展示、点击、购买计数及该词市场总计；同时保留原始字段名称、单位和统计定义。品牌汇总行不能冒充子 ASIN 行。
- **竞品点击率**：先查该词的 Search Query Details/可用明细；若确实返回对应 ASIN 的展示和点击计数，可以计算该来源下的点击率。不能因热门搜索词只有份额就断言所有入口都查不到点击率，也不能假定 SQP API 必然提供任意竞品的数据。
- **热门搜索词**：取得对应词、期间、部门/市场范围内返回的 clicked ASIN、点击份额及转化份额。它的前三是该词报表的前三，不是全站前三；其他明细的前十需核对排序依据，不能称为点击率或自然排名前十。
- **商品总销量**：我方用 Business Reports/订单等实际件数；竞品用允许的第三方销量估算，注明服务商、父体/单 ASIN、历史覆盖及估算方法。只有滚动月销时不能平均分成历史周销量。
- **商品识别信息**：需要图表或解释搜索吸引力时，取得对应 ASIN 主图、价格/币种、优惠、评分和评分数的日期快照。评分数包含只有星级的评价时，不称为文字评论数；核对是否父子共享。

报表中位价、当前售价和券后价分别保留，不能互相替代。同词市场总计可能在多个 ASIN 行重复出现，关联时只取同口径的一份，不能把它们相加。

每组数据保留来源/报表 ID 或文件、获取时间、覆盖起止日期、ASIN 与粒度、原字段/单位、筛选和截断情况。未进入已返回的前三/前十只表示未报告，不代表零；列表有缺口仍保留该竞品及缺失原因。

## 3. 计算与估算边界

先将百分比明确归一为小数或百分数；同一次计算只用一种表示。分母缺失或为零，结果为 `null`；已报告零购买且点击为正，转化率才为零。

```text
点击率 = 同 ASIN、同词、同期的点击计数 / 展示计数
点击后购买率（图中简写转化率）= 相同口径购买计数 / 点击计数
点击份额 = ASIN 点击计数 / 该来源市场点击总计
购买承接指数 = 热门搜索词转化份额 / 点击份额

若份额与总量属于同一统计总体：
估算点击量 = 点击份额 × 该词市场点击总计
估算关键词购买量 = 转化份额 × 该词市场购买总计
估算转化率 = 购买承接指数 × 该词市场购买总计 / 市场点击总计
```

- 点击份额不等于点击率，转化份额不等于转化率；query volume 不是 ASIN 展示量。SQP 字段名含 `Rate` 也要核对分母，不能仅凭名称代替上述计算。
- 直接报告的计数相除标为“报表实际值”；份额反推即使同口径也标为“估算”，保留份额四舍五入带来的影响。购买承接指数大于 1 只说明该来源里购买份额高于点击份额，不证明某主图导致效果。
- **跨报表先核分母**：同站、同词、同期、同 ASIN 只是必要条件。检查部门筛选、样本覆盖、购买定义及归因；若两份报告都有同 ASIN 点击计数/份额，核对是否一致。发现差异时保留各原值，不静默缩放、拼接或把前三份额补成 100%。
- 用户接受粗估不等于接受校验失败。跨报表换算须有统计总体兼容的依据；用可取得的同对象实际计数交叉校验，保留输入、计算值、实数与差异。若校验不过或已发现无法解释的差异，立即停用该估算并撤回依赖它的结论，旧结果只保留作错误追溯；不能仅加“粗估”标签、缩放系数或未知误差声明继续使用。总体未核齐且无可验证依据时，不输出绝对购买量/CVR估值，改用同来源份额或指数，明确哪些数据未取得、尝试过的合法来源与限制。恢复使用须先解决差异并重新核验，不预设统一误差阈值。
- 能取得同口径竞品购买与点击计数时，优先直接计算。不能用该商品全部销量除以某关键词点击量；也不能用 Business Reports 的 Units/Session 与关键词购买/点击冒充同一种转化率。
- 合并子体或期间时，仅对确认可加的计数先求和，再用总点击/总展示、总购买/总点击求率；不直接平均各行百分比。去重用户/订单等不可加指标需原生汇总，不能靠子体求和代替。
- 不编造误差为 ±某百分比。异常比率先查单位、计数定义和关联；不靠截断到 100% 或补零修复。解释小样本波动，尤其不能仅凭很少的购买计数判断转化恶化。

## 4. 总销量与入口分析

- 父体实际销量优先用该期间完整父体汇总，或同定义、无重复的子体/SKU 件数汇总；保留覆盖清单。核对当前与历史变体关系，不能默认今天的子体清单在历史期间也完整相同。
- 同父体多个竞品 ASIN 如果返回同一父体估算，只计一次，并注明对应子体；只有单 ASIN 估算就标“单 ASIN”，不能改称父体。未核齐两侧粒度时，标为范围不同的规模参考。
- 严格区分购买计数、订单数、订单项、件数和销售额。关键词购买量不等于商品总销量，父体总销量也不等于所选子体销量。
- 用户追问销量入口时，把全部可用搜索词、广告归因及零售总销量分开展示覆盖；搜索词行的相加不自动等于去重订单或完整搜索销量。广告与搜索数据可能重叠，不能相加成总销量，也不能用“总销量减广告”直接命名为自然搜索。
- 广告需覆盖同一期间，记录点击日/购买日和归因窗口、成熟度、广告商品/购买商品、其他 SKU 等范围。获取日报表的日期不是覆盖日期；若只有较晚快照或异期数据，写实际覆盖和获取日期，不能为简洁改标为目标周。

## 5. 趋势图与通俗交付

用户要求“同词、指定竞品、连续两周趋势图”时，直接按本模式绑定其精确关键词、ASIN和实际日期；其他词数、竞品或周期同样按当次要求，不把示例固定为默认范围。

按用户需要出图，不强制每个问题做完整图包。复用当前指定的简洁风格，不把某产品的品牌色、图片或固定版式变成全类目约束。

- 多关键词分别呈现；同词可并排“点击率”“转化率”“该词购买量”，父体/单 ASIN 总销量单独展示。标题或短副标题标明我方款式/ASIN、比较粒度和实际起止日期。
- 我方突出、来源明确的实际数据用实线、估算用虚线/“约”区分；标出双方数值。原始计数保留在证据中，展示小数位随精度和样本选择。单位统一，不能把 0.05、5 和 5% 混画。
- 缺失留空，单期仅画单点，缺口两侧不直接连成连续趋势；没有数据的对象说明原因，不能用旧数或零填满。竞品较多可分面/拆图，保留完整对象覆盖和稳定配色。
- 识别卡在主图缩略图旁放 ASIN、价格与币种、评分/评分数；同品牌多款不能只标品牌。价格和评分数标快照日期，不能假装是图上历史各周的价格/评价；历史主图不明时也标当前快照。
- 图内说明简短，例如“竞品虚线为粗估；空白表示缺数据”。公式与详细边界放随附证据，不能用专业长段落占满图。用户偏好对话内图表和白话时，不用大表格代替解释。
- 导出后实际看图：数据线与数值应在坐标范围内，百分比轴和图例对应正确，标签不重叠或被裁切，缩略图与 ASIN 一一匹配。图文件存在不算完成视觉检查。

## 6. 找到优先检查项

用“有没有被看到 → 看到了愿不愿点 → 点进来愿不愿买 → 整个商品卖了多少”解释，并区分数据观察与原因假设。

- 展示/份额不足：检查词与产品匹配、可售/收录、排名和流量覆盖；需要广告证据时交广告策略技能，不因总销量尚可就忽略核心词覆盖。
- 点击率偏低：同词同期同粒度对比后，联合看主图表达、价格/优惠、评分数量、配送、广告/自然位置和设备等差异；不能把全部差距归因于主图。
- 转化偏低或下降：单独查该词意图、落地款式、详情说明、价格优惠、配送/缺货和同期变化，保留点击/购买样本量。不同关键词的走势不能互相代替。
- 单款搜索表现与父体销量结论冲突：先核其他子体、其他词和入口覆盖，不把父体规模优势解释为该子体某词转化优势。

按证据强度、差距规模和可控性给少量优先项，写清改什么、依据、如何验证；数据不足就给待核假设。验证尽量同词同款、可比日期和展示条件，一次改变主要变量；不能把不同位置/流量混合的结果叫严格 A/B。需要主图方案、Listing 成稿或广告调整时，再进入对应的已授权任务。
