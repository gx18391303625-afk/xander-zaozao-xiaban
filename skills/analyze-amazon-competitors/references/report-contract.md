# 竞品分析报告契约

组织竞品分析报告时读取本文件。对标锁定使用 [benchmark-locking.md](benchmark-locking.md) 的专用交接；只有任务包含拍摄、图片、视频或 A+ 设计交接时，才另读 [visual-handoff.md](visual-handoff.md)。下方视觉简报与拍摄要求仅适用于视觉交接任务；仅分析竞品现有视觉内容，不自动要求制作我方图片简报。非视觉任务保留分析、证据与相关补证，省略我方图片交接部分。

只要求点击率、转化率或销量对比时，使用 [表现对标](query-performance-benchmarking.md) 的窄交付：指定范围的数值/趋势、实际与估算及缺口、优先检查项。下面的完整报告结构不自动适用。

## 档位输出契约

### 极速实战档

默认让用户在 30 秒内看到结论，按以下顺序交付：

1. **一句话打法**：打谁、主突破口是什么、首屏如何证明。
2. **竞品分层**：核心深看、标准对标、模式扫描及最强对手。
3. **我方优劣势**：优势、劣势、持平项和真正未知项。
4. **攻防结论**：一个主突破口、最多两个辅助理由、必须守住和明确不打。
5. **视觉简报（仅视觉交接任务）**：按用户指定数量与顺序输出；未指定时按买家决策顺序自适应。
6. **最少行动清单**：影响当前判断的验证动作，以及适用的设计素材与发布前核验。

涉及图片时正文保留最小 `I-ID → O-ID → E-ID/V-ID`，但不强制展示完整 13 节报告。用户最新确认的我方事实可直接进入设计策略；高风险主张的准确标志、适用范围与发布措辞放在简短核验栏，不用大段合规说明淹没做图任务。

### 深度尽调档

使用下方完整报告契约。完整呈现数据覆盖、证据账本、VOC、评分、反证、风险和补证计划，确保产品、运营和发布团队均可审计。
