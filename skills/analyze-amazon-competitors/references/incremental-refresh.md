# 竞品变化复核

先回答：谁改价、谁的信任壁垒变化、谁换了核心承诺，这是否改变当前对标判断？没有决策影响的普通波动不触发完整研究。

## 可比基线

保留全部用户 ASIN、原始顺序、身份状态和现有角色；新观察追加，不覆盖历史。报价资格、单位和可比范围统一使用 [证据检查](evidence-checks.md) 的记录，不把优惠消失或套装切换误认为同口径涨价。星级、评分数 `ratings` 与文本评论数 `reviews` 分开；共享评分范围变化先核准身份，不能写成评分暴增或归零。

时间线分别记录实际变更时间（未知留空）、首次观察时间及后续观察窗口。两次可比快照可证明期间观察值不同，不能把第二次采样日期当作实际改价日；新 ASIN 不能拼接为旧款历史。交付前运行证据检查的 timeline 部分，检查时序、身份和比较口径。窗口齐全也只支持时间关系，促销/改图造成销量变化仍需独立证据，不能由校验通过推导因果。

项目有共享版本机制时，按项目说明保留 `inputBindings(id/version/sha256)` 并验证范围与有效状态。旧角色仍是基线，不因此成为当前已验证结论。

## 变化到动作

| 观察 | 本轮动作 |
|---|---|
| 无相关变化，旧证据仍适用 | `REUSED`：引用原证据/时间，说明本轮核对范围；不宣称重新深拆 |
| 小幅动态变化但角色/对标带/主判断不变 | `SNAPSHOT_ONLY`：更新快照和差值，不重做评论与图库 |
| 到手价/套装、星级/评分数越过有依据的对标带，或核心承诺/形态改变 | `MATERIAL_REVIEW`：写明可能改变的判断，只重开受影响证据 |
| 无当前数据、身份/口径不同、字段缺失或相互冲突 | `NEEDS_VERIFICATION`：不计算虚假差值，不把缺失当下架/无变化/零评分 |

“实质变化”依据用户门槛、当前对标分布或具体决策影响，不预置统一涨跌百分比。新 ASIN 无基线标 `NEW_BASELINE`，按所需角色建立最小证据，不伪造变化率。

先聚焦查看变化字段。只有新信号可能改变购买理由、真实体验缺口或我方可证明优势，才复核相关详情、评论、图片；不是每次改价都重读整套页面。核心承诺只是竞品表达，不证明功能真实。没有变化信号但关键证据已过期/被撤销时，同样进入对应复核。

## 输出与交接

正文突出“变化 → 对标影响 → 下一步”；底稿保留全 ASIN 覆盖、前后值/日期/口径、证据 ID、所复用内容、未取得字段。角色确需调整时创建新锁定快照，记录前后角色及理由；不删掉被降级对象。刷新仅更新研究判断，不自动生成或执行商品投放、售价、Listing 或补货操作。
