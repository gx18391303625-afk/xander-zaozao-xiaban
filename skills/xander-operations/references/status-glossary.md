# 状态词白话对照

给用户看结果时，英文状态词后面必须跟一句白话。下表是统一说法，各模块都用它，不要自己另起名字。

## 改后台（写入）

| 状态 | 跟用户这样说 |
|---|---|
| `DRY_RUN` | 只是演练，没有真的改 |
| `API_STATE_VERIFIED` | 已经改好，并且读回来核对过，和提案一致 |
| `AWAITING_READBACK` | 亚马逊收到了，但还没生效/还读不到，过一会儿再核对 |
| `MISMATCH` | 改了，但读回来的值和提案不一样，需要人看一下 |
| `FAILED` | 亚马逊明确拒绝了，没改成 |
| `OUTCOME_UNKNOWN` | 不确定改没改成（比如超时）。**不会重发**，先核对再说 |
| `SKIPPED_STALE` | 提案生成后后台值已经变了，为安全起见没执行，需要重新出提案 |

## 分析结论

| 状态 | 跟用户这样说 |
|---|---|
| `READY` | 证据和规则都核过，可以拿去用（仍需你最后过目） |
| `PROVISIONAL` | 暂定：能先用，但有缺口，缺什么会列出来 |
| `BLOCKED` | 卡住了：关键事实缺失或冲突，先补这几项再继续 |
| `COMPLETE` | 这次该做的都做完了 |
| `RUN_BLOCKED` | 连原始数据都拿不到，这次没法做 |
| `SIMULATED / NOT LIVE` | 模拟数字，不是线上真实结果 |

## 计算器

| 状态 | 跟用户这样说 |
|---|---|
| `INCOMPLETE` | 缺核心数字，算不了（会列出缺哪个） |
| `PROVISIONAL`（广告经济线） | 有些可选成本按 0 算了，结果偏乐观 |
| `READY_ESTIMATED` | 输入齐全的估算，可以作为参考线 |
| `BLOCKED`（广告经济线） | 扣完成本已经不赚钱，没有广告空间 |
| `PARTIAL`（补货） | 缺日销或交期，只给了部分结果 |
| `COMPLETE_INPUTS` / `ESTIMATE`（利润） | 核心项都齐；有估算项时叫“暂定利润”，不是最终利润 |
| `KNOWN_SUBTOTAL_ONLY`（利润） | 缺核心项，只能给“已知收支小计”，不能叫利润 |

## 数据状态

| 说法 | 意思 |
|---|---|
| 生成中 / `IN_PROGRESS` / `PENDING` | 报表还没出来，**不等于 0** |
| `CANCELLED`（卖家报表） | 常见于该期间没有数据，但也不能直接当 0 |
| 未报告 / 未找到 | 数据源没返回这一项，不代表 0 或掉榜 |
| `UNKNOWN` | 不知道，不当 0 补 |

## 竞品机会决策

竞品证据检查器的状态只描述本次输入记录，不替代上面的整体分析结论：

| 状态 | 白话 |
|---|---|
| `PASS`（证据检查） | 已提供记录的一致性检查通过，不代表来源真实或研究完成 |
| `INCOMPLETE`（证据检查） | 相关记录缺证，只限制依赖这些记录的结论 |
| `INVALID`（证据检查） | 记录格式或内容有矛盾，先修正受影响部分 |

主攻候选 → 辅助候选 → 待验证 → 降级 → 阻断。被证据闸门或置信度压档时，会写出原因（例如“证据置信度未知，最高待验证”）。

## 关键词角色

| 角色 | 白话 |
|---|---|
| `CORE_VERIFIED` | 核心词，已验证，可进标题/五点 |
| `SECONDARY_VERIFIED` | 次级词，已验证，可进文案 |
| `INDEXING_CANDIDATE` | 只放后台搜索词，不进前台文案 |
| `LATER_STAGE_RELEVANT` | 以后阶段才用，现在不放 |
| `RELEVANT_NEEDS_VALIDATION` | 看起来相关，但还没验证，先不放 |
| `MARKET_CONTEXT` | 只做市场参考，不放 |
| `HOLD_CLAIM` / `UNSUPPORTED` | 对应卖点没证据，不放 |
| `BRAND_IP_ISOLATED` | 别人的品牌词，不放 |
| `WRONG_INTENT` | 搜的人要的不是我们这种东西，不放 |

- `DOCUMENT_NOT_SAVED`：平台已返回文档生成响应，但本机没有保存可用 PDF；没有自动重发，重新获取需要另一份明确批准。
